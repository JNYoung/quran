# 古兰经祷告 App MVP 实施计划

- 日期：2026-05-09
- 关联主文档：`2026-05-09-古兰经祷告App执行总文档.md`
- 所属批次：Batch 1 ~ Batch 4
- 状态：执行骨架已建立，后续持续细化

## 一、MVP 目标

先完成一套可配置内核，验证：
- 今日内容可稳定打开
- 用户可完成 Today -> Prayer -> Completion 闭环
- 推送可带来回流
- 离线状态下仍可阅读当天内容

## 二、MVP 范围

### 客户端必做
- Onboarding
- Today
- Prayer
- Completion
- History
- Settings
- 本地缓存
- 本地通知
- 远程推送接入

### 后端必做
- 内容拉取接口
- 配置拉取接口
- 推送调度接口/服务
- 内容版本接口

### 数据必做
- 用户设置
- 内容表
- 推送记录表
- 完成记录表
- 配置版本表

## 三、按批次拆解

### Batch 1
- 主工程初始化
- core / feature / platform / app shell 骨架
- Today / Prayer / Completion 跑通

### Batch 2
- 内容引擎
- 离线缓存
- 默认内容包

### Batch 3
- 远程推送
- 本地推送
- 去重
- 推送埋点

### Batch 4
- 四个 app 壳
- women mode 差异逻辑
- 配置化主题与内容包

## 四、里程碑

### M1
单壳客户端闭环可跑

### M3
