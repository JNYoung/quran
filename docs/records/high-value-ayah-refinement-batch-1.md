# 古兰经祷告 App 高价值 Ayah 精修标注第一批

## 一、目标

对第一批高价值 ayah 做人工精修标注，校正 bootstrap v1 的默认标签偏差。

## 二、精修样本（第一批 5 条）

### 1. Ayah `1:1`
- 建议 `theme_tags`：`gratitude`, `trust`
- 建议 `prayer_intents`：`need_gratitude_today`, `need_trust_today`
- 理由：开篇强调对真主的称颂与恩慈，适合作为感恩与信靠的入口。

### 2. Ayah `2:255`
- 建议 `theme_tags`：`trust`, `calm`
- 建议 `prayer_intents`：`need_trust_today`, `need_calm_today`
- 理由：强调真主的全知、永存与守护，适合安全感、安定感相关意图。

### 3. Ayah `24:35`
- 建议 `theme_tags`：`hope`, `trust`
- 建议 `prayer_intents`：`need_hope_today`, `need_trust_today`
- 理由：光的意象更适合作为引导、希望、被照亮的主题，而不只是抽象 trust。

### 4. Ayah `93:1`
- 建议 `theme_tags`：`hope`, `calm`
- 建议 `prayer_intents`：`need_hope_today`, `need_calm_today`
- 理由：清晨意象更适合新的开始、安静展开、走出低谷的语境。

### 5. Ayah `94:5`
- 建议 `theme_tags`：`hope`, `calm`
- 建议 `prayer_intents`：`need_hope_today`, `need_calm_today`
- 理由： hardship 后有 ease，是典型的安慰、安定、盼望型 ayah。

## 三、结论

这 5 条精修结果说明：
- bootstrap v1 可以起步
- 但高价值 ayah 必须人工精修
- 尤其 `hope / calm / gratitude` 这类高频内容位，不能长期被默认 `trust` 吃掉
