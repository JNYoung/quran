# 古兰经祷告 App 关键页面内容层级与线框说明

- 日期：2026-05-09
- 所属主线：产品
- 关联主文档：`2026-05-09-古兰经祷告App产品文档.md`
- 关联导航：`2026-05-09-古兰经祷告App-文档导航与拆分方案.md`

## 一、目标

进一步收口关键页面的信息层级，保证产品、设计、研发、运营对页面优先级理解一致。

## 二、Today 页面

### 内容层级
1. 问候 / 日期 / Hijri 日期
2. 今日 ayah 原文
3. 今日翻译
4. 今日主题一句话
5. 主按钮（Prayer / Reflection）
6. streak / 完成状态
7. 底部广告（远离核心区）

### 规则
- 首屏只能有一个主行动
- 广告不得进入前 5 层
- Women Mode 下第 5 层替换为更柔和入口

## 三、Prayer 页面

### 内容层级
1. 极简顶部返回
2. ayah 精简展示
3. prayer / remembrance 引导
4. 静默计时（可选）
5. 完成按钮

### 规则
- 无广告
- 无打断弹窗
- 无多余次要入口

## 四、Completion 页面

### 内容层级
1. 完成祝福
2. 今日 reflection
3. 收藏 / 分享 / 关闭
4. 底部广告位

### 规则
- 广告必须排在祝福与 reflection 之后
- Women Mode 下标题与祝福语更柔和

## 五、History 页面

### 内容层级
1. 日期筛选 / 标题
2. 历史内容列表
3. 完成状态
4. 底部广告

## 六、Settings 页面

### 内容层级
1. 提醒时间
2. 语言
3. Women Mode
4. 通知权限引导
5. 后续去广告入口

## 七、结论

这套页面层级的重点，不是多功能，而是保护 sacred flow：
- Today 负责接住推送
- Prayer 负责保护安静时刻
- Completion 负责承接情绪与变现
