# 古兰经祷告 App Women Mode 产品规则文档

## 一、文档目标

Women Mode 不是一个小开关，也不是“给女性版多加一个功能”。

它是这条产品线里最关键的差异化产品规则之一，目标是：
- 在女性特殊阶段维持 spiritual connection
- 降低 religious pressure
- 让 app 表现出“理解女性状态”，而不是默认男性使用逻辑

## 二、Women Mode 的产品定义

Women Mode 是一套体验切换规则，不只是一个页面状态。

当用户进入该模式时，产品需要同步改变：
- Today 页主语气
- 推送语气
- Prayer 引导方式
- Completion 的定义
- 内容主题优先级
- 广告展示边界

## 三、Women Mode 触发方式

建议支持两种：

### 1. 手动触发
- 用户在 Settings 中主动开启
- 用户在首页轻入口中快速切换

### 2. 持续模式
- 用户可设置“保持此模式直到我手动关闭”

第一阶段不强制做复杂周期预测，不做重健康功能。

## 四、Women Mode 下的体验变化

## 1. Today 页面

普通模式强调：
- 今日 ayah
- 今日 prayer prompt
- 开始祷告

Women Mode 强调：
- 今日 ayah
- 今日 gentle reflection
- 今日 dua / remembrance prompt
- 降低“必须完成某个动作”的压力

### 页面变化原则
- 主按钮文案更柔和
- 不使用带任务感的提示
- 允许 Today 成为“陪伴页”而非“任务页”

## 2. Push 语气

普通模式可强调节律与持续性。

Women Mode 必须：
- 不制造“今天没完成”的压力
- 不暗示宗教表现不足
- 更像陪伴与提醒，而不是督促

## 3. Prayer 页面

Women Mode 下，Prayer 页面可降级为：
- reflection mode
- dua mode
- quiet remembrance mode

重点是：
- 保持 spiritual moment
- 不强推标准 prayer completion 心智

## 4. Completion 页面

Women Mode 下，不建议继续叫“完成祷告”。

建议替换成更柔和的表达，如：
- 今日陪伴已完成
- 今日安静时刻已留给自己
- 今日 remembrance 已记录

## 五、Women Mode 内容规则

Women Mode 内容优先级：
- gentleness
- healing
- calm
- emotional safety
- self-acceptance
- quiet trust

不优先：
- 强责任感
- 强纪律感
- 强任务完成感

## 六、Women Mode 运营规则

- 推送与内容必须成套切换
- 内容审核时单独检查 Women Mode 语气
- 广告不得贴近 Women Mode 说明内容
- 节日专题也需要有 Women Mode 变体

## 七、Women Mode 成功标准

要验证的不是“用户有没有开这个开关”，而是：
- 女性用户是否更愿意持续打开
- 是否减少因压力感导致的流失
- 是否能提升完成温和 ritual 的频次

## 八、结论

Women Mode 是这条产品线真正的产品能力，不是装饰性功能。

它需要被当作：
- 产品规则
- 内容规则
- 推送规则
- 测试规则

四条线共同维护。
