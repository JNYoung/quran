## 四、当前缺口与重叠

## 1. 缺口

当前最明显缺 4 类内容：

### A. 本地 dev backend 文档
目前只在 E2E 和执行逻辑里提到了需要本地服务，但还没有单独定义：
- 服务职责
- 技术选型
- 路由范围
- seed 数据加载方式

### B. 数据字段级细节
表结构还没有明确：
- 字段
- 索引
- 版本规则
- 去重键
- women mode 字段

### C. 接口 schema 细节
接口还没写清：
- 请求字段
- 响应字段
- 错误码
- 幂等规则

### D. 测试矩阵
测试流程有了，但还没有形成：
- 按平台
- 按 app 壳
- 按网络状态
- 按 women mode
的验证矩阵

## 2. 重叠

### 产品文档 vs 技术方案
有少量关于推送与内容结构的重叠。

处理原则：
- 产品文档保留“为什么这么做”
- 技术方案保留“怎么实现”

### 技术方案 vs 客户端模块化架构
有少量关于模块拆分的重叠。

处理原则：
- 技术方案保留全局系统视角
- 客户端模块化文档保留客户端实现视角
