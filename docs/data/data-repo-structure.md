# Data Repo Structure

This document explains how the local Quran dataset is organized inside the repository.

## Included
- Raw Arabic Quran source
- Raw English `en.asad` translation
- Quran splitting script
- Ayah labeling script
- Per-surah output files
- Ayah indexes
- Intent / theme indexes
- Ayah label records

## Purpose
This makes the repository self-contained for:
- local development
- seed data preparation
- ayah refinement work
- future content pipeline automation
