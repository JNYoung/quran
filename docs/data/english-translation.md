## 一、目标

把开发期英文译文层进一步收口，不再停留在“可用多个英文译本”的状态。

## 二、当前原则

MVP 阶段必须固定一个主英文译本，原因：
- 保证内容一致性
- 保证审核口径一致
- 保证 seed、E2E、Today、Push 不混用不同翻译风格

## 三、当前建议

基于当前开发期稳定性与一致性优先的原则，正式确定：
- **主英文译本：`en.asad`（Muhammad Asad）**
- 使用 `AlQuran Cloud` 中的 `en.asad` 作为 MVP 阶段唯一 runtime 英文译本

## 四、执行建议

### 当前最稳做法
- 开发期固定使用 `en.asad`
- 其他译本只作为交叉阅读或人工校验，不进入 MVP runtime

### 原则
- 运行时只用一个主译本
- 校验时可参考第二来源
- 译本变更必须视为版本变更

## 五、待办

### P0
- [x] 在 AlQuran Cloud 中最终固定 1 个英文 edition 标识：`en.asad`
- [ ] 在 seed 数据与 dev backend 中统一使用该标识

### P1
- [ ] 记录备用英文译本标识
- [ ] 建立译本迁移规则

## 六、结论

开发期不能“同时支持很多英文译本再说”，而要先固定一个主译本。

当前正式结论：
- **MVP 主英文译本 = `en.asad`**

这样 Today / Push / Prayer / Seed / E2E / Dev Backend 都能保持一致。
