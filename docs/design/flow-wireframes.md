## 一、目标

把关键流程和首批页面线框收口成统一说明，便于后续真正出设计图。

## 二、关键流程

### 主流程
- Push / Direct Open
- Today
- Prayer / Reflection
- Completion
- Return

### Women Mode 流程
- Push
- Today（gentle mode）
- Reflection / Dua
- Soft completion

## 三、首批必须出图页面

### 1. Onboarding
- 语言选择
- 提醒时间选择
- 通知权限引导

### 2. Today
- 默认模式
- Women Mode
- 节日模式（可先做 Friday）

### 3. Prayer
- 默认模式
- Women Mode / Reflection Mode

### 4. Completion
- 默认模式
- Women Mode

### 5. Settings
- 提醒设置
- Women Mode
- 语言

## 四、线框重点

### Onboarding
- 信息少
- 步骤短
- 只保留必要选择

### Today
- 顶部轻问候
- Ayah card 为绝对主角
- 主按钮单一明确
- 广告位不进入首屏主层

### Prayer
- 极简
- 沉浸
- 几乎无杂质

### Completion
- 祝福与 reflection 在前
- 广告在后
- 情绪收尾而非任务结算
