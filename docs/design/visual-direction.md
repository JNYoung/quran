## 一、目标

这条产品线的设计目标，不是做“华丽宗教 App”，而是做：
- 安静
- 有尊重感
- 易读
- 高留白
- 不打断 spiritual flow

设计系统需要服务 4 个 app，但不能做成 4 套完全割裂的视觉语言。

## 二、统一设计原则

### 1. Sacred Flow First
任何视觉设计都要服从：
- 经文可读
- Prayer 不被打断
- Completion 有余韵
- 广告不抢戏

### 2. Calm Over Excitement
- 不追求强刺激
- 不做高饱和、强动效、强促销感视觉
- 更像安静陪伴，而不是增长型工具

### 3. Soft Hierarchy
- 重点不是大标题压人，而是温和的层级引导
- 用留白、字号、对齐、卡片间距建立秩序

### 4. Cross-App Shared System
- 4 个 app 共用同一套基础设计系统
- 差异主要通过主题包、色彩语气、插画与 copy tone 表达

## 三、设计系统层级

建议设计系统拆成 4 层：

### 1. Foundation
- 色板
- 字体
- 字号层级
- spacing
- 圆角
- 阴影
- RTL 规则

### 2. Component
- ayah card
- reflection card
- primary button
- quiet timer
- bottom banner slot
- women mode notice

### 3. Page Pattern
- Today pattern
- Prayer pattern
- Completion pattern
- History pattern
- Settings pattern

### 4. Theme Pack
- ID male
- ID female
- ME male
- ME female

## 四、统一视觉基调

### 基础关键词
- calm
- clean
- respectful
- breathable
- minimal

### 避免关键词
- flashy
- gamified
- crowded
- promo-heavy
- hyper-colorful

## 五、颜色方向

### 通用底色建议
- 米白 / warm white
- 浅沙色
- 极浅灰绿 / 灰蓝

### 功能色原则
- 主色只做轻强调
- 不做高饱和大面积铺底
- 状态色也要柔和处理

## 六、字体与排版方向

### Arabic
- 优先可读性
- 行距充足
- 不追求装饰性过强的花体

### English / Indonesian
- 现代、安静、可读
- 不要太科技感

### 排版原则
- 经文原文必须是第一阅读层
- 翻译是第二层
- reflection 是第三层
- 按阅读节奏自然下沉

## 七、组件风格原则

### Ayah Card
- 清晰边界
- 高留白
- 原文优先
- 不和广告或杂项信息挤在一起

### Primary Button
- 圆角柔和
- 视觉稳定
- 不做强刺激 CTA

### Completion Card
- 更像余韵卡片，而不是任务结算卡片

### Women Mode Notice
- 温柔但不“粉色刻板化”
- 更强调理解感与安静感

## 八、广告位视觉原则

- 广告必须和内容区明确分层
- 不伪装成内容卡片
- 不进入 Quran / Prayer 核心视觉层
- Completion 页广告也要留足缓冲空间

## 九、四个 App 的视觉方向

### 印尼男性版
- 清爽、稳定、微克制
- 更偏晨间感与节律感

### 印尼女性版
- 温柔、洁净、陪伴感
- 可略多一点柔和暖意

### 中东男性版
- 庄重、简洁、留白更强
- 更强调 Arabic-first 的秩序感

### 中东女性版
- 私密、沉静、高级
- 不可过甜，不可幼态化

## 十、结论

这条产品线的设计系统，本质上是“安静的秩序系统”。

真正重要的不是做得多炫，而是：
- 经文清楚
- 情绪稳
- 页面不吵
- 祷告不被打断
