## 一、目标

## 二、ASO 核心任务

### P0
- [ ] 为 4 个 app 建立关键词方向表
- [ ] 明确品牌名 / 副标题 / 一句话定位是否可检索
- [ ] 明确印尼市场和中东市场的关键词差异
- [ ] 明确男性版 / 女性版关键词差异

### P1
- [ ] 建立商店截图文案策略
- [ ] 建立 description 结构模板
- [ ] 建立竞品关键词观察表

### P2
- [ ] 建立 A/B 测试计划（标题 / 副标题 / 首图）
- [ ] 建立版本更新文案模板
