# 古兰经祷告 App 推送运营 SOP

- 日期：2026-05-09
- 所属主线：运营
- 关联主文档：`2026-05-09-古兰经祷告App推送策略文档.md`
- 关联导航：`2026-05-09-古兰经祷告App-文档导航与拆分方案.md`

## 一、目标

推送运营的目标不是多发，而是稳定维持 daily spiritual loop。

## 二、日常运营动作

每天至少确认：
- 今日 4 个 app 的主推送内容是否齐全
- today 内容与 push 文案是否一致
- women mode 替换文案是否准备好
- Friday / Ramadan / Eid 是否需要 campaign 覆盖

## 三、推送运营流程

### Step 1：确认今日内容版本
- 检查 today 内容卡片是否发布

### Step 2：确认推送文案
- 主推送文案
- 女性版第二提醒文案
- women mode 替换文案

### Step 3：确认发送节奏
- 默认时段
- 是否节日覆盖
- 是否需要对低活跃用户降频

### Step 4：发送后检查
- 查看送达情况
- 查看打开率
- 查看是否存在双响或错配

## 四、运营规则

- 一天默认 1 条主推送
- 女性版第二提醒默认谨慎开启
- 7 天未打开用户应降频
- 节日可增强，但不能破坏克制感

## 五、异常检查

重点监控：
- 推送文案与 today 内容不一致
- women mode 未切换到替换文案
- 同一天重复触达
- 节日专题覆盖失败
