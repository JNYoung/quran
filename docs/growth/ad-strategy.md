## 一、文档目标

这条产品线的广告不能按普通工具类 App 的思路处理。

因为这里的核心使用场景是：
- Quran 经文阅读
- 安静祷告
- spiritual reflection

所以广告策略要同时满足两件事：
- 能变现
- 不破坏神圣感与陪伴感

## 二、广告的基本定位

广告在这个产品里，不应该表现为“强打断的商业插入”，而应该是：
- 低侵入
- 有边界
- 不争夺用户注意力中心
- 不伪装成 devotional 内容

### 广告定位原则
- 广告是产品的次级层，不是主角
- 广告不能和 Quran、Prayer、Reflection 争抢页面中心
- 广告不能让用户觉得“我在祷告时被打断了”

## 三、广告位策略

## 1. 允许放置的页面

### Today 页面
允许：
- 页面下方远离首屏核心经文区的 banner

限制：
- 首屏不能出现广告
- Quran 主卡片上下不能贴广告

### History 页面
允许：
- 页面底部 banner
- 列表间低频插入（第二阶段再评估）

### Saved 页面
允许：
- 页面底部 banner

### Completion 页面
允许：
- 祝福/反思内容之后的广告位
- 可作为主要变现场景

## 2. 严格禁止的页面/区域

绝不允许：
- Prayer 页面
- Quran 核心经文阅读区中段
- Women Mode 说明区附近
- 节日祝福内容主区域中段
- 首次打开 Today 页的第一屏主视觉附近

## 四、广告调性

广告调性是这条产品线很重要的边界。

### 允许的广告感受
- 安静
- 克制
- 边缘化
- 不喧宾夺主

### 不允许的广告感受
- 大促销感
- 闪烁感
- 强 CTA 感
- 情绪操控感
- 冒犯 religious atmosphere 的强商业感

### 页面视觉规则
- 广告块与 devotional 内容之间必须有明显留白
- 广告区背景不要伪装成内容卡片风格
- 广告标识必须清楚
- 不允许让用户误以为广告是推荐经文、推荐 dua 或推荐 reflection

## 五、广告内容调性要求

虽然实际广告内容很多时候来自广告平台，未必完全可控，但产品侧必须至少控制以下原则：

### 1. 类目控制
尽量避免：
- 明显低俗
- 夸张博彩气质
- 高噪音游戏买量创意
- 明显擦边内容
- 强冲动消费类素材

### 2. 情绪控制
避免：
- 吵闹
- 高刺激
- 强对比大字促销风
- 倒计时式压迫感

### 3. 语境控制
广告不应在整体体验中显得“和 spiritual context 完全冲突”。

## 六、4 个 App 的广告调性差异

## 1. 印尼男性版
- 广告风格偏简洁
- 不要太花哨
- 更适合普通静态 banner

## 2. 印尼女性版
- 广告在视觉上更要柔和
- 避免太硬的促销语气
- Women Mode 场景下更要克制

## 3. 中东男性版
- 更强调庄重感
- 绝不能出现很跳的视觉破坏整体氛围

## 4. 中东女性版
- 广告需要更低噪音
- 更强调私密感与安静感保护

## 七、Women Mode 下的广告规则

Women Mode 是广告规则的特殊高敏场景。

### 原则
- 不把广告贴着 women mode 提示文案放
- 不在 gentle reflection 首屏附近放广告
- 不在 women mode 下提高广告频率

### 建议
- Women Mode 下只保留底部低侵入广告位
- 必要时可降低某些页面的广告展示概率

## 八、节日场景下的广告规则

### Friday
- 保持常规克制
- 不因为 Friday 就增加广告强度

### Ramadan
- 不建议同步增强广告频率
- 节日流量增加不应直接转化为更重打扰

### Eid
- 更应弱化商业感
- 节日祝福场景不要让广告抢戏

## 九、频控规则

建议广告频控至少遵守：
- 同一页面重复进入不应频繁刷新视觉强差异广告
- Completion 页面是主广告场景，但不能每次都过强打断
- Women Mode 与节日场景默认更保守

## 十、广告成功标准

要看的不是单纯 CTR，而是平衡指标：
- completion 页面广告曝光是否稳定
- 是否影响次日留存
- 是否在 women mode 场景引发反感
- 是否在中东版场景引发明显体验失衡

## 十一、广告失败信号

出现以下情况，说明广告调性失控：
- 用户感觉 Quran 内容像广告前菜
- Completion 页祝福被广告压住
- Women Mode 体验被商业感打断
- 节日场景里广告比内容还抢眼

## 十二、结论

这条产品线的广告策略本质上不是“怎么多放”，而是“怎么在不破坏 sacred flow 的前提下存在”。

广告调性必须被当作产品规则来管，而不是投放细节。
