# 古兰经祷告 App 广告运营规则

- 日期：2026-05-09
- 所属主线：运营
- 关联文档：`2026-05-09-古兰经祷告App-广告策略与调性文档.md`
- 关联导航：`2026-05-09-古兰经祷告App-文档导航与拆分方案.md`

## 一、目标

把广告从“默认接入”变成“受规则约束的运营模块”。

## 二、核心运营规则

### 1. 页面优先级
- Completion 页是主广告页
- Today 页仅保留远离主内容的底部广告
- Prayer 页永不投放

### 2. 人群优先级
- Women Mode 默认更保守
- 中东女性版默认更保守
- 节日场景默认更保守

### 3. 频控原则
- 不以短期曝光最大化为目标
- 同一天内避免过度重复感
- 节日不自动放大广告强度

## 三、投放检查清单

每次广告策略调整前检查：
- 是否侵入首屏主内容
- 是否贴近 women mode 说明或 gentle reflection
- 是否在 Friday / Ramadan / Eid 场景显得过于商业
- 是否与 app 调性冲突

## 四、异常信号

重点监控：
- 某页面跳出率异常上升
- Completion 页停留下降
- 女性版用户反馈变差
- 节日场景里留存明显下滑

## 五、后续待补

- 广告位命名规范
- placement 与 frequency cap 模板
- 广告复盘模板
